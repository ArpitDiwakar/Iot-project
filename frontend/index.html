    About the Project

    A B.Tech CSE project that teaches a computer to recognise ten kinds of animals from photographs. Tap a question to read the short answer.

    What is animal image classification?

    It is the task of looking at a photo and choosing one label from a fixed list. Here the list has 10 animals, and the model decides which one is most likely present in the picture.

    What is deep learning?

    Deep learning is a part of machine learning that uses neural networks with many layers. Instead of us writing rules such as "cats have pointed ears", the network learns useful patterns on its own from thousands of labelled examples.

    What is MobileNetV2?

    MobileNetV2 is a compact convolutional neural network designed by Google to run fast with little memory. It was first trained on the large ImageNet dataset, so it already knows how to detect edges, textures, shapes and parts of objects.

    What is transfer learning?

    Transfer learning reuses a network that has already learned from a huge dataset. In this project the MobileNetV2 base is frozen, and only a small new classifier on top (global average pooling, dropout and a 10-way softmax layer) is trained on the Animals-10 images.

    Why is image classification useful?

    It powers photo search, wildlife monitoring, farm and livestock management, medical imaging, quality inspection and many accessibility tools. It is also one of the best first projects for learning computer vision.

    Animal Categories

    The model knows exactly these ten animals. Anything else, such as a car or a person, will still be forced into one of them.

    How It Works

    From your upload to the final answer, in seven steps.

    1. You upload an animal image

      Pick a JPG, JPEG or PNG file in the classifier.

    2. The frontend sends it to the API

      The browser posts the file to the FastAPI backend as multipart form data.

    3. The backend converts it to RGB

      Every image gets exactly three colour channels, whatever its original format.

    4. The image is resized to 180 × 180

      This is the same size the model was trained on.

    5. The MobileNetV2 model processes it

      The saved model scales the pixels with MobileNetV2 preprocessing, then extracts features and classifies them.

    6. The model scores 10 classes

      A softmax layer turns the output into ten probabilities that add up to 100%.

    7. The website shows the top 3

      You see the most likely animals with confidence scores and progress bars.
